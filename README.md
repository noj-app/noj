# NOJ — تطبيق العميل

**من الدفع تبدأ علاقتك المالية.**

NOJ منصة سعودية تربط العميل بالتاجر، وتحوّل الشراء من عملية دفع تنتهي عند
الفاتورة إلى علاقة مالية مستمرة. من لحظة الدفع، يحصل العميل على فاتورته
وخدماته وولائه — بلا رسائل مزعجة.

هذا المستودع يحتوي **تطبيق العميل** (نسخة الويب/الجوال) في ملف واحد:
`index.html`.

## تشغيل المشروع

لا حاجة لأي تثبيت أو خادم أو اتصال بالإنترنت. افتح الملف مباشرة:

```
open index.html      # macOS
xdg-open index.html  # Linux
```

أو شغّل خادم ثابت بسيط لتجربته كتطبيق ويب على الجوال:

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` من متصفح الجوال.

بيانات الدخول التجريبية:
- أي رقم جوال سعودي بصيغة `05xxxxxxxx`
- رمز التحقق: `1234`

## الشاشات

| الشاشة | الوصف |
|---|---|
| شاشة افتتاحية | شعار NOJ والشعار التسويقي، تنتقل تلقائياً لتسجيل الدخول أو الرئيسية |
| تسجيل الدخول | رقم جوال سعودي + رمز تحقق مكوّن من 4 خانات |

| الفواتير | قائمة قابلة للبحث، مع تفاصيل كل فاتورة في نافذة منبثقة |
| الولاء | رصيد النقاط، المستوى الحالي، شريط التقدم، استبدال المكافآت |
| تحليل المصروفات | مخطط دائري للفئات، اتجاه شهري بالأعمدة، رؤى نصية تلقائية |
| التنبيهات | قائمة إشعارات (فواتير، دور، عروض، ولاء) |
| المزيد | الإعدادات، الدعم، تسجيل الخروج |

الشريط السفلي: **الرئيسية · التنبيهات · الولاء · التقارير · المزيد**.

## القواعد المعمارية (إلزامية)

هذه القواعد ثابتة لأي تعديل مستقبلي على المشروع:

1. **ملف واحد بلا اعتماديات خارجية.** كل شيء — HTML وCSS وJavaScript —
   يعيش داخل `index.html`. ممنوع استخدام أي مكتبة أو إطار عمل أو CDN أو
   خط خارجي. يجب أن يعمل التطبيق بالكامل دون اتصال بالإنترنت.
2. **عربي RTL بالكامل.** `<html lang="ar" dir="rtl">`، وكل نص، وكل تخطيط
   يُبنى بمنطق RTL أصلاً (لا تصحيحات لاحقة). الأرقام والهواتف تُعرض بأرقام
   غربية (Western digits) مع اتجاه `ltr` معزول داخل السياق العربي لتفادي
   مشاكل bidi في تجميع الفواصل والفاصلة العشرية.
3. **أيقونات SVG مضمّنة فقط.** لا صور خارجية، لا أيقونات من مكتبات أيقونات؛
   كل الأيقونات معرّفة كسلاسل SVG داخل كائن `ICONS` في الجافاسكربت.
4. **هوية الألوان** (متغيرات CSS في `:root`):
   - كحلي `--navy: #12235C`
   - أزرق `--blue: #2D7BF4`
   - ذهبي `--gold: #C99A2E`
   - خلفية `--bg: #F7F8FC`
5. **دعم `prefers-reduced-motion`.** أي حركة أو انتقال يُعطَّل تلقائياً
   عبر media query عند تفعيل هذا الإعداد في نظام المستخدم.
6. **مصدر واحد للحقيقة للأرقام.** كل الأرقام المعروضة (إجمالي المصروفات،
   نسب الفئات، الاتجاه الشهري، نقاط الولاء) يجب أن تُشتق حسابياً من كائن
   `DB` وقائمة `invoices` في الجافاسكربت — لا تُكتب كنصوص ثابتة منفصلة في
   أكثر من مكان. أي فاتورة تحتوي بنود تفصيلية يجب أن يتساوى مجموع بنودها
   مع إجمالي الفاتورة تماماً.

## بنية الكود داخل `index.html`

- **`<style>`**: كل التنسيقات، بما فيها متغيرات الهوية اللونية وmedia
  query الخاص بتقليل الحركة.
- **`ICONS`**: كائن يحوي كل أيقونات SVG كسلاسل نصية جاهزة للحقن عبر
  `innerHTML`.
- **`CATEGORY_META`**: ربط كل فئة إنفاق بأيقونتها ولونها في المخطط الدائري.
- **`DB`**: بيانات تجريبية (Mock) للمستخدم، الفواتير، الولاء، الانتظار،
  والتنبيهات. هذا هو مصدر الحقيقة الوحيد للأرقام المعروضة.
- **دوال الحساب** (`computeTotal`, `computeCategoryTotals`,
  `currentTier`): تشتق كل الأرقام المعروضة من `DB` وقت العرض.
- **دوال الشاشات** (`renderHome`, `renderQueue`, `renderInvoices`,
  `renderLoyalty`, `renderReports`, `renderNotifications`): تُعيد رسم كل
  شاشة عند التنقل إليها اعتماداً على حالة `DB` الحالية.
- **`goTo(screen)`**: التنقل بين الشاشات (تبديل class فقط، بلا تحميل صفحات).
- **النوافذ المنبثقة** (`openModal`/`closeModal`): تفاصيل الفاتورة، الملف
  الشخصي، تأكيد استبدال المكافأة.

## بيانات تجريبية

كل البيانات (الفواتير، النقاط، الانتظار، التنبيهات) بيانات وهمية لأغراض
العرض التوضيحي فقط. عند ربط التطبيق بخدمة فعلية، يجب استبدال كائن `DB`
بطبقة استدعاء بيانات حقيقية مع الإبقاء على نفس دوال الحساب لضمان اتساق
الأرقام بين الشاشات.

## اختبار التغييرات

بما أن المشروع بلا أدوات بناء، يكفي فتح `index.html` في متصفح وتجربة
المسارات يدوياً:

1. تسجيل الدخول برقم صحيح `05xxxxxxxx` ورمز `1234`.
2. التأكد من تطابق إجمالي المصروفات في الرئيسية مع مجموع الفواتير ومع
   المخطط الدائري في التقارير.
3. التأكد من أن مجموع بنود أي فاتورة يساوي إجماليها في نافذة التفاصيل.
4. تجربة استبدال مكافأة والتأكد من خصم النقاط وتحديث شريط التقدم في نفس
   اللحظة.
5. تفعيل "تقليل الحركة" في نظام التشغيل والتأكد من اختفاء كل الانتقالات.
